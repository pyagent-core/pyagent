PyAgent is a production stack for building, running, and observing multi-agent LLM systems, maintained under the pyagent-core GitHub organization (github.com/pyagent-core/pyagent) with documentation at pyagent.org. It is MIT licensed, requires Python 3.11+, and is organized as a set of composable packages rather than one monolithic library.

The stack rests on four pillars: Blueprint (declare agents, workflows, and providers in a single YAML file, validated and compiled without boilerplate Python), Execution (a consistent API covering 18 named orchestration patterns — such as Pipeline, Supervisor, Fan-Out, Debate, Voting, Role-Based, ReAct, and Swarm — for coordinating agent collaboration, plus difficulty-aware routing that picks the cheapest capable model for a task), Context/Memory (a three-tier, trust-aware memory system spanning working, session, and semantic retention, with built-in PII redaction and sensitivity tiers), and Observability (OpenTelemetry-based distributed tracing, cost tracking, and an integrated web dashboard for monitoring and governance).

Concretely, the project ships as several pip-installable packages, including pyagent-blueprint (YAML spec and compiler), pyagent-patterns (the 18 orchestration/resolution/structural/advanced patterns), pyagent-providers (provider-agnostic routing across OpenAI, Anthropic, Google Gemini, LangChain, LiteLLM, or custom adapters), pyagent-router (cost-optimized model selection), pyagent-compress (token compression and budget enforcement), pyagent-context (the memory layer), pyagent-trace (OpenTelemetry integration), and pyagent-studio (a CLI and web dashboard for simulation and governance). Installing pyagent-all pulls in the full stack.

It is worth noting that "PyAgent" is not a unique name — a web search turns up several unrelated GitHub projects using the same or a similar name (e.g., tonio-lora/pyagent, an autonomous multi-agent software development pipeline; UndiFineD/PyAgent, a similar autonomous dev-pipeline project; and gitpavleenbali/pyagent, described as "the Pandas of AI Agents"). Among these, the pyagent-core/pyagent project documented at pyagent.org is the one specifically built and marketed as a general-purpose orchestration framework for multi-agent LLM systems, and is the most relevant match for that description.
